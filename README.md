One word for my Wi-Fi: **Gaslighting**.

It shows full bars, insists it is connected, and loads nothing. The router
is fine. The signal is excellent. Nothing works, and somehow it is my fault
for standing in the wrong room.

`main.ts` writes that single word to `/output/entry.txt`.
